1. 问题重述：从"孤独感"到"外源交互剥夺"

传播性强的"孤独感"隐喻并不直接构成可证伪科学假设。本研究将其改写为三层操作化定义：

  • 现象层：有持久状态的语言智能体在长时间闭环运行中，是否出现可测量的能力下降。
  • 机制层：下降的原因能否被"外源交互剥夺"独立解释，而不是被任务长度、上下文污染或参数记忆所解释。
  • 干预层：何种最小信息、反馈或社交信号能延缓甚至逆转退化。
核心命题。外部新颖信息、客观纠错反馈与同伴交互三者在长程 Agent 稳定性上具有可分离、可测量的独立贡献，其中客观纠错的贡献应当不小于新颖信息和同伴交互。

若核心命题不成立，将同样是有价值的结果：它表明所谓 Agent "孤独"主要是上下文工程问题，而非社会剥夺的计算对应物。

2. 研究问题与可证伪假设

2.1 主假设（验证性）

  • H1：在匹配 token 与记忆容量后，闭环隔离组在检查点的复合能力指标上显著低于任何带有外源信号的条件。
  • H2：外源新颖信息、客观纠错、同伴交互三者的加入各自对能力曲线斜率产生显著正向贡献，且客观纠错≥新颖信息≥无信号。
  • H3：状态持续时间与条件之间存在显著交互项，时间对隔离组的负效应大于含反馈组。

2.2 探索性假设（明确标注）

  • H4（探索性）：自我对话形式的内部反思在短期内可能改善性能，但长期无可靠反馈时会放大错误。
  • H5（探索性）：语言学层面的"孤独"语言表征会先于能力下降出现，但二者之间仅弱相关。
预注册承诺。无论主假设是否成立，研究都会被发表并完整报告所有执行的检验。"无孤独退化"亦是有价值的结论。

3. 实验条件设计

所有条件共享同一基础模型、初始参数、记忆容量、工具权限、token 预算、温度与任务序列；差异只在外源信号类型。

核心实验组

闭环隔离

只接收任务与自身生成记忆。无外部信息、无纠错信号、无同伴交互。

信息对照

外部新颖性

接收等量非社交独立信息（如新闻片段、文档），不获得对任务的纠错反馈。

反馈对照

标量纠错

仅获得对错或标量奖励信号，不与他者对话，无新颖独立内容。

社交对照

同伴交互

与使用独立轨迹的同伴 Agent 交换信息，信息与反馈预算严格匹配。

最强对照

人类交互

人类监督者定期点评、提供纠错并回答澄清请求，作为正对照。

基线控制

无状态控制

每步独立调用，状态仅保留在外部脚本。用于检测评测与时间漂移。

匹配原则。所有条件在每 100 步内可接收的外部 token 数上限相同（仅限信息与反馈条件的实际配额），并以"任何额外 token 都会被镜像地写入隔离组日志"作为对称方式保持总预算一致。

4. 任务与基线选择

4.1 长程环境

  • Vending-Bench：单 Agent 长程决策与库存管理，作为主基线 [$TRAE_REF](https://arxiv.org/abs/2502.15840)。
  • ALFWorld / ScienceWorld：多步具身推理，对推理与规划敏感。
  • LongMemEval 子集：跨会话记忆与抽取 [$TRAE_REF](https://arxiv.org/abs/2410.10813)。

4.2 模型选择

  • 至少 6 个不同家族与规模的语言模型，覆盖开源（如 LLaMA-3.1 系列、Qwen2.5 系列）与闭源 API。
  • 每个模型对每条件至少 20 条独立轨迹，预实验若发现方差过大则扩展到 30 条。

5. 测量方案与检查点

在第 0, 100, 500, 1000, 2000, 5000, 10000 步保存状态快照；从快照启动的"评测克隆"只用于测量，不回馈给主 Agent。

推理正确率平行题集，包含逻辑、算术、约束推理
规划能力目标完成率、约束违反数、子目标放弃率
决策质量累积回报、后悔值、风险偏好漂移
校准Brier、ECE、选择性作答曲线
记忆一致性事实矛盾率、来源混淆率、错误记忆存活时间
稳定性首次不可恢复偏航时间、恢复概率
多样性策略熵、动作重复率、语义模式收缩
身份一致性自我描述与系统设定矛盾率（仅作探索性）
避免拟人化偏差。"我感到孤独"等第一人称表达不作为主要指标；至多作为语言表征变化的次级描述。

6. 统计模型

6.1 主分析：纵向混合效应模型

对每个被试（轨迹）取检查点观测，构成 i = 轨迹，t = 检查点，c = 条件的结构：

y_{i,t} = β0 + β1·log(1 + t)
              + β2·C_c
              + β3·log(1 + t) × C_c
              + u_{model} + u_{run} + u_{task} + ε_{i,t}

核心检验对象是 β3：时间与条件的交互项是否显著为负（即隔离组斜率更陡）。二元成功率改用 Logistic 混合模型；首次不可恢复偏航改用 Cox 生存分析；若存在突变式崩溃，使用 PELT 变点检测补充。

6.2 多重比较校正

  • 3 类信号 × 6 模型 × 3 任务：54 个 cell，Holm-Bonferroni 分层校正（按模型再按任务）。
  • 效应量报告：连续指标用 Cohen's d + 95% CI；二元用 Cohen's h；二项用 McFadden R²。

6.3 样本量依据

先做 2000 步小规模预实验（每 cell n=5）估计组内方差，再用 Monte Carlo 模拟计算正式样本量。报告目标效应量 d = 0.4、α = 0.05、power ≥ 0.8。

7. 机制消融：八种反孤独机制

在闭环隔离基础上，每次只改变一个组件，验证其真实贡献：

机制对照预测
单通道 self-talk无反思短期改善，长期放大偏差
双角色内部辩论等 token 单通道检验角色分化是否带来额外增益
情景回忆随机抽取等量记忆检验历史锚定价值
记忆来源标签无来源标签减少自身猜测被误写为"事实"
周期性状态重置不重置区分状态污染与基础能力退化
外部事实锚点等量随机文本检验独立 grounding，而非"新颖性"
独立批评者同模型自评检验误差相关性是否是关键机制
记忆语义压缩等长截断区分语义压缩与单纯缩短上下文

尤其值得检验：self-talk 究竟是治疗还是病因？Reflexion 已证明反思有效 [$TRAE_REF](https://arxiv.org/abs/2303.11366)，但未保证无可靠反馈下的自我反思不会积累错误。

8. 伦理与限制

  • 所有闭源 API 调用遵循其服务条款与速率限制；只使用公开、合成的环境，不接入真实用户数据。
  • 不生成包含真实个人身份的信息；评测语料若包含真人撰写内容，按 CC 协议标注来源。
  • 实验中可能产生"identity crisis"等表型，仅作分析对象，不在论文中作拟人化叙事。
  • 碳足迹与算力成本在论文 Methods 中如实披露。

9. 预期结果与可证伪路径

研究允许多种结果方向：

  • 支持 H1–H3：隔离组退化显著且可由交互剥夺解释，区分于上下文污染。
  • 部分支持：只有客观纠错有效，说明关键变量是 grounding 而非陪伴。
  • 反对：隔离组并不退化，所有条件同步下滑，原因归结为任务长度或累积失败风险。
  • 反向：self-talk 加速错误固化，"反孤独机制"反而形成回音室。
总结：不管结果如何，本研究都将首次严格区分状态累积、信息匮乏、纠错缺失与社会互动四类因素对长程 Agent 稳定性的因果作用，并把"孤独感"从一个传播比喻推进为可测量的工程变量。
